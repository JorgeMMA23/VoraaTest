# Compilar proyectos

## NodeJS

```bash
cd restaurant_NodeJS
npm install
npm run dev
```

---

## React

```bash
cd restaurant_React
npm install
npm run dev
```

---

## Flutter Android

```bash
cambiar baseUrl de rest_app/lib/core/di/injection.dart a la url local de NodeJs 
cd rest_app
flutter pub get
flutter run
```
